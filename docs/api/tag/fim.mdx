### Request Body \(required\)

<details open>

<summary>Request Body</summary>

#### max\_tokens

_Type Signature:_ `integer | null`

#### min\_tokens

_Type Signature:_ `integer | null`

#### model

ID of the model to use. Only compatible for now with:
  - `codestral-2405`
  - `codestral-latest`

_Example:_

```
codestral-2405
```

_Type Signature:_ `string`

#### prompt

The text/code to complete.

_Example:_

```
def
```

_Type Signature:_ `string`

#### random\_seed

_Type Signature:_ `integer | null`

#### stop

Stop generation if this token is detected. Or if one of these tokens is detected when providing an array

_Type Signature:_ `string | array<string>`

#### stream

Whether to stream back partial progress. If set, tokens will be sent as data-only server-side events as they become available, with the stream terminated by a data: [DONE] message. Otherwise, the server will hold the request open until the timeout or until completion, with the response containing the full result as JSON.

_Default Value:_ `false`

_Type Signature:_ `boolean`

#### suffix

_Example:_

```
return a+b
```

_Type Signature:_ `string | null`

#### temperature

_Type Signature:_ `number | null`

#### top\_p

Nucleus sampling, where the model considers the results of the tokens with `top_p` probability mass. So 0.1 means only the tokens comprising the top 10% probability mass are considered. We generally recommend altering this or `temperature` but not both.

_Default Value:_ `1`

_Type Signature:_ `number`

</details>
