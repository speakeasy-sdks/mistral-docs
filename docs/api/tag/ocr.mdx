# ocr

## POST /v1/ocr

Operation ID: ocr_v1_ocr_post

OCR

### Request Body \(required\)

<details open>

<summary>Request Body</summary>

##### document

Document to run OCR on

Type Signature: `DocumentURLChunk | ImageURLChunk`

<details open>

<summary>DocumentURLChunk Properties</summary>

##### document\_name

The filename of the document

Type Signature: `string`

##### document\_url

Type Signature: `string`

##### type

Type Signature: `'document_url'`

</details>

<details open>

<summary>ImageURLChunk Properties</summary>

##### image\_url

Type Signature: `ImageURL | string`

<details open>

<summary>ImageURL Properties</summary>

##### detail

Type Signature: `string`

##### url

Type Signature: `string`

</details>

##### type

Type Signature: `'image_url'`

</details>

##### id

Type Signature: `string`

##### image\_limit

Max images to extract

Type Signature: `integer`

##### image\_min\_size

Minimum height and width of image to extract

Type Signature: `integer`

##### include\_image\_base64

Include image URLs in response

Type Signature: `boolean`

##### model

Type Signature: `string`

##### pages

Specific pages user wants to process in various formats: single number, range, or list of both. Starts from 0

Type Signature: `array<integer>`

</details>

### Responses

#### 200 \(application/json\)

Successful Response

<details open>

<summary>Response Body</summary>

##### model

The model used to generate the OCR.

Type Signature: `string`

##### pages

List of OCR info for pages.

Type Signature: `array<OCRPageObject>`

<details open>

<summary>OCRPageObject Properties</summary>

##### dimensions

The dimensions of the PDF Page's screenshot image

Type Signature: `OCRPageDimensions`

<details open>

<summary>OCRPageDimensions Properties</summary>

##### dpi

Dots per inch of the page-image

Type Signature: `integer`

##### height

Height of the image in pixels

Type Signature: `integer`

##### width

Width of the image in pixels

Type Signature: `integer`

</details>

##### images

List of all extracted images in the page

Type Signature: `array<OCRImageObject>`

<details open>

<summary>OCRImageObject Properties</summary>

##### bottom\_right\_x

X coordinate of bottom-right corner of the extracted image

Type Signature: `integer`

##### bottom\_right\_y

Y coordinate of bottom-right corner of the extracted image

Type Signature: `integer`

##### id

Image ID for extracted image in a page

Type Signature: `string`

##### image\_base64

Base64 string of the extracted image

Type Signature: `string`

##### top\_left\_x

X coordinate of top-left corner of the extracted image

Type Signature: `integer`

##### top\_left\_y

Y coordinate of top-left corner of the extracted image

Type Signature: `integer`

</details>

##### index

The page index in a pdf document starting from 0

Type Signature: `integer`

##### markdown

The markdown string response of the page

Type Signature: `string`

</details>

##### usage\_info

Type Signature: `OCRUsageInfo`

<details open>

<summary>OCRUsageInfo Properties</summary>

##### doc\_size\_bytes

Document size in bytes

Type Signature: `integer`

##### pages\_processed

Number of pages processed

Type Signature: `integer`

</details>

</details>
